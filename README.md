# Mathe-Merkheft

Sechs eigenständige Lernseiten zu Brüchen, Zahlenstrahl und Dezimalzahlen. Einstieg: `index.html`.

## GitHub Pages
1. Neues öffentliches Repository `Mathe-Merkheft` auf GitHub erstellen.
2. Alle Dateien aus diesem Verzeichnis in das Stammverzeichnis des neuen Repositories laden.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` und `/(root)` → Save.
4. Veröffentlichung unter `https://BENUTZERNAME.github.io/Mathe-Merkheft/` prüfen.

Keine externen Bibliotheken erforderlich.
